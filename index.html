1 The team

Each person has a colour, taken from the sticky notes they used on the board. Everything you write on this site is tagged with your name and your colour, so the rest of the team always knows who said what.

How to use this site: click Pick your name in the top-right, choose yourself, and then click the 💬 button under any note, project or section to add a note or a question. Your notes show up in your colour, here and in the All Notes feed.

2 Sharing notes with the team

This site is a set of static files, so it runs fine on GitHub Pages with nothing behind it. Notes are saved in your own browser immediately. To make them shared, the board stores notes as comments on one GitHub issue — everyone points at the same issue and sees the same notes.

One-time setup, per person

  1. Open an issue in the team repo, call it Board notes, and note its number.
  2. Make a fine-grained personal access token with Issues: Read & write, limited to that one repository.
  3. Click the ⚙ button up top, fill in the repo, the issue number and your token, then Save & sync.

If you skip the setup

The board still works. Your notes save in your browser, and you can use Export notes in the ⚙ panel to send them to the team as a file, which anyone can pull in with Import notes.

⚠ About the token

Your token is kept only in your own browser. Never commit a token into these files and never paste someone else's. If a token ever leaks, revoke it on GitHub — it takes one click.
